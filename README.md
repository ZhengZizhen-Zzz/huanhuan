# 缓缓 Huanhuan

**给想吃的念头，一个暂停的地方。**

下午卡在一道难题上，想点一杯奶茶；下班后没什么事，手又伸向零食。明明想调整饮食，那个瞬间却很难停下来。

缓缓围绕这样的日常时刻，设计了一次轻巧的陪伴：看看当下的状态，把想吃的食物收进暂存袋，做一段短互动，再决定接下来怎么做。日历里的印章与逐渐丰富的贴纸收藏，则把一次次尝试留下来，成为下次愿意回来的理由。

**当前为可交互 Web 原型，面向小程序形态探索。** 手机单页操作，电脑可并排浏览三个主页面。

![缓缓三个主页面：缓一缓、日历、收藏](preview.png)

## 从一个日常困扰出发

项目最初的问题是“怎样让人忍住不吃”。经过需求讨论、三轮小红书公开内容调研和原型迭代，问题逐渐收敛为：

> 当一个已经知道健康饮食道理的人，因为压力或无聊开始找零食、刷外卖时，怎样让一次短暂停顿变得足够顺手、足够愿意尝试？

这决定了缓缓的两个重点：**当下有一个能立刻做的动作，之后有一份值得回看的积累。**

| 研究与探索 | 已形成的产出 |
| --- | --- |
| **3 轮公开内容调研** | 阅读 72 篇去重帖子详情，提取需求、行为、顾虑与反例 |
| **2 个优先场景** | 压力下寻求安慰、无聊时寻找刺激；按当次状态分流 |
| **6 版界面探索** | 从鼓励文案与装饰贴纸，走向可操作的暂存袋和按需展开的信息 |
| **3 个主页面** | 即时互动、日历反馈、贴纸收藏，串联完整体验 |

72 篇是定性观察的帖子数；6 版是设计版本数。研究口径与证据见 [用户研究](RESEARCH.md)，版本对比见 [设计演进](DESIGN-STORY.md)。

## 一次缓缓如何发生

| 01 · 缓一缓 | 02 · 留下一次记录 | 03 · 看见自己的积累 |
| --- | --- | --- |
| 选择饿了、嘴馋或心情不好，也可以跳过。选一份食物，收进袋子、点击砸碎，或跟着节奏呼吸。 | 完成后记录“暂时不吃”“吃了”或“还没决定”。不必为了留下记录，先给出一个标准答案。 | 周/月历呈现当次记录；每日健康饮食章单独确认。次数与贴纸逐渐累积，让努力有具体的样子。 |

**试一条最短路径：** 打开原型 → 点击首页奶茶贴纸 → 暂存 → 记录结果 → 查看日历与收藏。完整路径支持文字输入、本地食物照片预览和自定义提醒。

## 三个塑造体验的决定

### 把帮助放在输入前面

冲动发生时，长问卷和一整页建议可能成为新的负担。状态、食物均可跳过，首页贴纸本身就是入口。缓缓先让用户做一个小动作，再留下必要的记录。

### 让贴纸参与功能

奶茶和面包可以被操作，日历上的贴纸对应一次记录，收藏袋承接互动奖励。视觉元素贯穿“暂存—记录—收藏”，让可爱与功能发生关系。

### 给再次尝试留下位置

一次吃了，也可以回来记录；一天的章和一次没吃零食分开统计。产品希望承接持续尝试，奖励机制也需要同时关注成就感与记录意愿。

## 研究如何改变方案

公开讨论中同时出现了“知道道理但当下做不到”“替代活动太费劲”“记录让我看到积累”，以及“虚拟点单后依然想真正下单”等相反线索。由此形成四项取舍：

- 优先压力与无聊场景，将泛化的“减肥工具”收敛到具体时刻。
- 将前置分类改为可跳过，保留直接互动入口。
- 保留日历、次数和收藏，将“是否愿意回来”单独验证。
- 把模拟点外卖、热量识别和预测提醒放入分阶段探索，先验证核心体验。

完整的“观察—判断—方案—验证”过程见 [产品思考](CASE-STUDY.md)。

## AI 将用在哪里

下一阶段的 AI 重点是**场景化替代行动**：例如，同样是“压力大想喝奶茶”，在办公室、宿舍和通勤途中，可执行的办法不同。

方案采用经过审核的内容库进行 RAG 检索，由 Harness 管理输入约束、来源校验、失败回退和评估。当前互动、记录和收藏由确定性逻辑实现，AI 服务处于方案阶段。详见 [AI 设计](AI-ROADMAP.md)。

## 项目进度与下一步

已完成需求探索、用户场景拆解、六版界面迭代和浏览器中的交互闭环。接下来通过访谈与七日试用回答三个问题：**想吃时会不会打开，互动有没有帮助，积累反馈会不会带来回访。** [查看验证计划](VALIDATION.md)。

原型采用示例日期与初始统计，新增记录保存在本机浏览器；食物图片仅本地预览。微信适配、通知、识别和 AI 服务是后续开发范围。

<summary>本地运行与实现</summary>

下载仓库后，用浏览器打开 `index.html` 即可体验。也可在项目目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8000`。原生 HTML / CSS / JavaScript，无构建依赖；Pointer Events 支持拖动，localStorage 保存本机记录。日期固定为 2026-10-08，初始统计为示例。验收记录见 [TESTING.md](TESTING.md)。
